# Field migration

Source audited: original GitHub commit aa8599a19ca8045ff924428609084a4070e6ae6d, verified against the app at localhost:4001; see docs/legacy-sample-provenance.json and docs/template-language-review.md. The complete original input/select/textarea inventory is preserved in tests/fixtures/legacy-fields.json. Runtime medication rows and Benzathine penicillin G date fields are listed separately below. Canonical values live in memory, with reusable facts shared between four retained editor states. Document-specific dates, calculations, prose and archives belong to their own template. The original letterBody maps to the rich bodyText block; document.body is its validation identifier. Definitions, validation, language resources and calculations are shared by all four routes.

Section-inclusion controls are document membership, not patient facts. Removing a section retains its values and edited content in the current session. The old salutation/nationality “none” choices now use empty/omitted optional phrases; they do not assert absence. On explicit user instruction, inserting Retroviral Infection defaults medication pick-up to today and supply to 60 days; inserting Active Syphilis defaults treatment start to today and the original first regimen choice, Benzathine penicillin G. These highlighted fields are editable and retained manual values take priority. Medication tablet counts and administration times remain unfilled. Doctor preferences are the only persisted clinical-adjacent values.

All date fields expose a format/CE-BE/slash-free-entry hint. Full dates allow eight digits and ten formatted characters; TPT month/year allows six digits and seven characters. National ID allows thirteen digits and seventeen characters. Entry limits reject oversized pastes without changing the prior value; existing invalid data is retained for correction rather than silently truncated. Unit inputFitsField/registry tests and browser ergonomics.spec.mjs cover these controls. Choice fields use automatic floating keyboard menus; Enter/Tab preserve values when no choice is made.
